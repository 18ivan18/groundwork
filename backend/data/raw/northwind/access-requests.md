# Requesting access to systems

Access at Northwind Labs is granted per person, for a reason and for a limited time. Request it with
the **access form** in the IT portal.

## What you can request

| Access | Approval | Expires after |
|---|---|---|
| Staging systems | Automatic for engineers | No expiry |
| Production dashboards (Lantern) | Automatic for engineers | No expiry |
| Production database, read only | Your manager | 30 days |
| Production database, write | Your manager and the platform lead | 7 days |
| Production admin (Shipyard, secrets) | The platform lead | 7 days |
| Finance systems | The finance controller | 90 days |
| HR systems | The head of people | 90 days |

## Rules

- Say why you need the access and link the ticket or incident.
- Access expires automatically. Request it again if you still need it.
- During a SEV1 incident, the incident commander can grant production write access for **24 hours**
  without the form. The grant must be written in the incident channel and is reviewed afterwards.
- Never share credentials or sessions, even with a colleague who has the same access.
