Design notes

  • Filters, sort and page live in the URL (/library?collection=northwind&status=failed), so a view can be shared.
  • Only documents the user can see are listed; there is no “hidden documents” count.
  • Checkboxes appear on every row, but the bulk bar says how many the user may actually delete. Delete is offered only for documents the user owns (or for admins).
  • Status: Indexed, a progress state while a job runs (links to Jobs), or Failed with the reason in the drawer.
  • Protected collections (the demo corpora) can only be changed by admin.
