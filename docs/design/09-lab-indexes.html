New index

The LLM context costs about $3.10 and 35 minutes for 12,000 chunks at the current rate limit (estimate). Contexts already in the cache are free. Header + context + chunk must fit the embedder's 512 tokens: context is capped at 80 tokens.

Design notes

  • Making an index active swaps the alias and bumps its generation; every worker reloads BM25 and the answer cache misses. Confirmation dialog names both indexes.
  • The cost estimate uses the chunk count from a dry-run chunking pass and the configured model prices.
  • The active index can't be deleted or retired; retire first frees nothing until deleted.
  • Admin only. The whole Lab section is hidden for other users and its routes return 404.
